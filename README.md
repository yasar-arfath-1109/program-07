# SQL Lab Assignment – Marksheet Table

## Objective

To learn how to create a table, insert records, filter records using `WHERE`, and sort records using `ORDER BY`.

## Problem Statement

Create a `Marksheet` table with the following fields:

- RollNo
- Name
- Department
- Marks

Insert the following records:

| RollNo | Name | Department | Marks |
|---|---|---|---:|
| 1 | Arun | CSE | 85 |
| 2 | Divya | IT | 78 |
| 3 | Karthik | CSE | 92 |
| 4 | Nisha | ECE | 67 |
| 5 | Rahul | IT | 88 |

### Tasks

1. Create the `Marksheet` table.
2. Insert all 5 records.
3. Display students whose marks are greater than 80.
4. Sort the result in descending order based on Marks.

## Instructions

4. Do not modify `test.sh`.
